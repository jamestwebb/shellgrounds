If a student says "it's not working"

SymptomCause & what to say
"My flag is rejected"Flags are per-student — a classmate's flag never validates. Tell them to click the green flag in the terminal to copy it exactly, rather than retyping.
"Handle already claimed"Someone took it, or they registered before and cleared their browser. Pick a new handle. (To free one, delete that player in Netlify Blobs.)
"I ran the command, nothing happened"Check the blue path in their prompt — they may be in a different directory. Most challenges accept short or full paths, but the file must exist from where they stand. cd ~ returns home.
"It says command not found"If it's a real Linux command we don't simulate (top, nano), the game says so explicitly. Genuine typos say "command not found".
"The act is locked"Each act opens after solving all but one of the previous act's challenges. Topside (WIN) is always open.
"Nothing printed"Correct for cd and redirects. The game prints "(no output — in a shell, silence usually means success)".
Lost all progressProgress is tied to the browser token. Same browser = resumes automatically. Different machine = new handle needed.

Accepted command variants

Auto-completing challenges accept the natural variations a beginner types, so a correct command is never silently ignored:

  • Optional quotes: cat "Documents/case_notes.txt"
  • Path prefixes: ./Documents, ~/Documents, /home/analyst/Documents
  • Short paths when already in the folder: head -n 5 access.log from inside Documents
  • Flag spacing: head -n 5, head -n5, head -5
  • Windows: forward or back slashes, any capitalization (md5 or MD5)
  • Trailing spaces are ignored everywhere

Teaching notes

  • The Coach (toggle in the terminal title bar) explains every command and error in plain language. Explanations fade after the second use of a command. Leave it ON for beginners.
  • Reference tab holds a manual page for every command, and tells students the real-shell equivalent (man grep). Point stuck students there rather than giving the answer.
  • Course tie-ins: Act III's WSL bridge is exactly what Case 001 §1C asks students to figure out unaided. Act V's offset-carrying mirrors Case 003's mmls → fsstat -o chain. Act IV's pipes and redirection are Case 005's core skills.
  • Unsimulated tools (mmls, vol, exiftool) reply with what they are and which case uses them — a free preview of the semester.
  • Hints: first is free, later ones cost XP. Hint use is visible in the instructor dashboard as a signal of where the class is struggling.
