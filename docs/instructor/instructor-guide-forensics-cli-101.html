Quick reference
Set your own site URL and class password before handing this out. The admin handle is whatever you put in ADMIN_HANDLES — instructor, say; there is no default, and the setting ships empty.
Handles: 3–20 characters, letters/numbers/underscore/hyphen, claimed once only.
30 challenges · 885 points total · finds look like FIND{ABCD2345EFGH} and are different for every student.
How the difficulty fades — Act I briefs show the whole command, and the free hint repeats it. From Act II the brief names the tool but not its flags or arguments, and the exact line moves into a hint that costs XP. By the last act the brief states only the objective. A student who never buys a hint has genuinely recalled every command. Hint spend is visible in the instructor dashboard, so it reads as a difficulty signal rather than as cheating.

If a student says "it's not working"

SymptomCause & what to say
"My flag is rejected"Flags are per-student — a classmate's flag never validates. Tell them to click the green flag in the terminal to copy it exactly, rather than retyping.
"Handle already claimed"Someone took it, or they registered before and cleared their browser. Pick a new handle. (To free one, delete that player in Netlify Blobs.)
"I ran the command, nothing happened"Check the blue path in their prompt — they may be in a different directory. Most challenges accept short or full paths, but the file must exist from where they stand. cd ~ returns home.
"It says command not found"If it's a real command we don't simulate (top, nano), the game says so explicitly. Genuine typos say "command not found".
"I don't know which command to use"Intended from Act II on. Point them at the free hint first, then the Reference tab. The costed hint is the safety net, not a failure.
"The act is locked"Each act opens after solving all but one of the previous act's challenges.
"Nothing printed"Correct for cd and redirects. The game prints "(no output — in a shell, silence usually means success)".
Lost all progressProgress is tied to the browser token. Same browser = resumes automatically. Different machine = new handle needed.

Act IV: The Pipeline

Pipes, redirection, filters, and multi-stage analysis

40 pts · act4-grep-v · OKFilter the Noise (Inverted Grep)

Task: Documents/network_stream.log is almost all ordinary allowed traffic, and the one line that matters is buried in it. Show only the packets that were NOT allowed, then submit the find on the CRITICAL_DATA_LEAK entry.
Answer: grep -v "ALLOW" Documents/network_stream.log
Completion: Submits a flag · flag is inside /home/examiner/Documents/network_stream.log
Hint 1 (free): grep normally keeps the lines that match. One find inverts that and keeps everything else.
Hint 2 (−10 XP): Run grep -v "ALLOW" Documents/network_stream.log.

45 pts · act4-pipe-count · OKFirst Pipeline (grep | wc -l)

Task: Your report needs a number, not a listing: how many packets in Documents/network_stream.log were not allowed? Get that count onto the screen and nothing else. A pipeline is the classic way to do it, but this challenge grades the number you produced, so any command that prints the right count scores.
Answer: wc -l then grep -v "ALLOW" Documents/network_stream.log | wc -l then grep -vc ALLOW Documents/network_stream.log
Completion: Auto-completes on: outputEquals
Hint 1 (free): The | operator feeds one command's output straight into the next, and wc -l counts lines.
Hint 2 (−10 XP): Run grep -v "ALLOW" Documents/network_stream.log | wc -l. The shorter grep -vc ALLOW Documents/network_stream.log reaches the same number and is accepted too.
Also accepted: grep -v "ALLOW" Documents/network_stream.log | wc -l, grep -vc ALLOW Documents/network_stream.log, grep -vc "ALLOW" Documents/network_stream.log, cat Documents/network_stream.log | grep -v ALLOW | wc -l

45 pts · act4-pipe-csv · OKExtracting Fields (cut and grep)

Task: Documents/security_events.csv is comma separated, and the rows tagged FLAG_EMIT carry a token in column 6. Isolate those rows, cut out just that column, and submit the token.
Answer: grep "FLAG_EMIT" Documents/security_events.csv | cut -d, -f6
Completion: Submits a flag · flag is inside /home/examiner/Documents/security_events.csv
Hint 1 (free): Two commands joined by a pipe: grep picks the rows, cut picks the column. cut needs to be told the delimiter and the field number.
Hint 2 (−10 XP): Run grep "FLAG_EMIT" Documents/security_events.csv | cut -d, -f6.

50 pts · act4-redirect · OKOutput Redirection (>)

Act V: Closing the Case

Read the partition table, carry the offset, carve the container

60 pts · act5-scan · OKRead the Partition Table

Task: evidence/seized_drive.raw is the raw image of the drive that left the building, and an encrypted container is somewhere inside it. mmls is the Sleuth Kit tool that prints a disk image's partition table: where each partition starts, how long it is, and what kind it is. Nothing can be carved until you know which sector the container begins at.
Answer: mmls evidence/seized_drive.raw
Completion: Auto-completes on: allOf
Hint 1 (free): mmls takes the path to the image and nothing else. Then read the Start column of the row that says Encrypted Container.
Hint 2 (−10 XP): Run mmls evidence/seized_drive.raw. The container is slot 002, and the Start it reports is the number the next challenge wants.
Also accepted: mmls ./evidence/seized_drive.raw, mmls /home/examiner/evidence/seized_drive.raw
Instructor note: Students must READ the Start sector offset from the table; the capstone no longer prints it for them.

120 pts · act5-capstone · OKCarve the Container (Finish Line)

Task: This is the whole case in one command line. dd copies a REGION of a file rather than all of it: bs=512 makes each of its blocks one sector, and skip= counts how many of those blocks to step over before it starts reading. Hand it the sector mmls gave you and it lifts the container out of evidence/seized_drive.raw; hand it a different number and it copies the wrong bytes without complaining.
Answer: dd if=evidence/seized_drive.raw of=container.img bs=512 skip=41 then cat container.img
Completion: Auto-completes on: allOf
Hint 1 (free): dd reads with if=, writes with of=, and needs two more things: how big a block is, and how many blocks to step over before it starts. A sector is 512 bytes.
Hint 2 (−20 XP): Run dd if=evidence/seized_drive.raw of=container.img bs=512 skip=41, then cat container.img to read what came out.
Also accepted: dd if=evidence/seized_drive.raw of=container.img bs=512 skip=41 count=4, dd bs=512 skip=41 if=evidence/seized_drive.raw of=container.img, dd if=/home/examiner/evidence/seized_drive.raw of=/home/examiner/container.img bs=512 skip=41
Instructor note: Chains off act5-scan. A wrong offset is rejected by the tool, so a student who skipped the scan must go back.

Accepted command variants

Auto-completing challenges accept the natural variations a beginner types, so a correct command is never silently ignored:

  • Optional quotes around a path
  • Path prefixes: ./Documents, ~/Documents, or the full absolute path
  • Short paths when already inside the folder
  • Flag spacing: head -n 5, head -n5, head -5
  • Windows: forward or back slashes, any capitalization (md5 or MD5)
  • Trailing spaces are ignored everywhere

Teaching notes

  • The Coach (toggle in the terminal title bar) explains every command and error in plain language. Explanations fade after the second use of a command. Leave it ON for beginners.
  • Reference tab holds a manual page for every command, and tells students the real-shell equivalent. Point stuck students there before they buy a hint.
  • Unsimulated tools reply with what they are, rather than a bare "command not found".
  • Hints: the first is free and conceptual; the one that gives the exact command costs XP. Hint use is visible in the instructor dashboard as a signal of where the class is struggling.
  • Watch the stuck points. The dashboard flags any challenge with a solve rate under 35%. Now that briefs no longer contain the answer, that number means something: it marks a concept the class did not get, not a typing error.
