# Windows CMD Essentials Pack

**Curriculum Type:** Windows Command Prompt (cmd.exe) & Batch Administration  
**Target Audience:** Students, IT technicians, system administrators, and security examiners.  
**Platform:** Windows Command Prompt (cmd.exe)

## Learning Objectives
1. **Act I — Navigation & Inspection:** `cd`, `dir /a /b /s`, `type`, `tree /f`, and `where`.
2. **Act II — File Management & Batch:** `copy`, `move`, `ren`, `del`, `md`, `rd`, `attrib`, `cls`, and `%USERPROFILE%` environment variables.
3. **Act III — Filtering & Diagnostics:** `findstr /i /r /c:`, `type ... | find /c /v ""`, `tasklist`, `ipconfig /all`, `systeminfo`, and `certutil -hashfile`.
