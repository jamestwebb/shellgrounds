# Forensics CLI 101 Pack

**Curriculum Type:** Digital Forensics & Incident Response (DFIR)  
**Target Audience:** Students in introductory cyber forensics courses.  
**Platforms:** Linux (Warren TTY1) & Windows (Topside CMD)

## Learning Objectives
- Master fundamental CLI navigation, directory hierarchy traversal, and file inspection.
- Identify real file types via magic bytes without relying on file extensions.
- Compute and verify cryptographic checksums (`md5sum`, `sha256sum`, `certutil`).
- Build multi-stage pipelines (`grep`, `cut`, `wc -l`, `sort`, `uniq`) to process unstructured security logs.
- Understand cross-platform bridging (WSL `/mnt/c` mounts) and Windows CMD parity (`dir /a`, `type`, `findstr`, `attrib`).
- Analyze partition geometry and carve evidence partitions using sector offsets.
