# Linux Fundamentals Pack

**Curriculum Type:** Core Linux Systems & Command Line Engineering  
**Target Audience:** Students, engineers, and analysts learning the Linux terminal.  
**Platform:** Linux (Sandbox TTY1)

## Learning Objectives
1. **Act I — Navigation & Files:** `pwd`, `ls -la`, `cd`, `cat`, `head`, `tail`, and wildcard globbing (`*`, `?`).
2. **Act II — Text Streams & Pipelines:** `grep`, `wc -l`, `sort`, `cut`, `tee`, standard pipes (`|`), and redirection (`>`, `>>`).
3. **Act III — File Operations & Permissions:** `touch`, `mkdir -p`, `cp -r`, `mv`, `rm`, octal and symbolic `chmod`, `stat`, and `sudo`.
4. **Act IV — Advanced Shell & Scripting:** `find -name`, `sed s///`, `awk`, `diff`, quotes (`"$VAR"` vs `'$VAR'`), and exit status `$?` with `&&` / `||`.
